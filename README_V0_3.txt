MAIN CHANGES
- Proper reusable noun phrases.
- Determiners appear in most noun phrases.
- Adjectives can stack from zero to seven.
- Compound subjects: “the X and the X...”
- Compound objects: “...the X and the X.”
- “of” phrases: “the shadow of the machine.”
- Predicate adjectives: “it was strange and beautiful.”
- Prepositional openings.
- Most thoughts now contain a verb.
- Connectors are used to join phrases rather than appearing randomly.
- One fragmentary structure remains for useful damage.

The machine still deliberately ignores some English inflection rules.
This is poetry, not customs inspection.
